## Data
- Memory 0x11810000+0x3488/+0x348c: two boolean words written by mainapp_model_detect (c015d7e0) encoding which hardware model the unit is -- B1 IV=(0,0), B1X IV=(0,1), G1 IV=(1,0), and (inferred) G1X IV=(1,1). Compared against reference strings in table c0180fd8 (step ~6-7 bytes per candidate) vs. the flash-stored model string at c00fa014.
- Memory 0x11810000+0x3130: 32-entry EDMA TCC-completion-callback table; register via c015c94c, clear via c015c984 (edma_callback_table_clear).
- Memory 0x11810000+0x3494: shared event/status-flags object; c015c860/c015c8d4 OR bits into its various bit-packed sub-fields under the B14[150] lock; c015c9a0/c015ca14 read a hardware EDMA-base pointer from its word 0 and use it to reach DRAE1 (+0x348) and IESR (+0x2260).
- Memory c011aa18/c011aa28/c011aa40/c011aa4c/c011aac0: the USB interface-ownership tables (recon/18,20) -- reset by c015c620/c015c814, registered/looked-up by c015c66c/c015c6b4/c015c788, seeded by c015c804.
