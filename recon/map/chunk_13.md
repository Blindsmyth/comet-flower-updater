# chunk_13: c0153730..c0157876 (150 functions)

Summary: this range covers several distinct clusters. (1) A MainApp/MIDI event-dispatch core (c01537a8 mainapp_event_dispatch, c01537f4, c0153788) and the param-buf "resync" apply path (c0153820, c01538f4) that sits alongside the param_buf_* family already mapped in chunk_09/11. (2) McASP0 TX/RX EDMA setup (c0153cb8, c0153d6c), already identified by recon/16. (3) A large RhythmService pattern/transport-state engine (c0153f00..c0154290 and c0156430..c0156660): byte flags at 0xc011ada4-adad, B14[50/51/184/208/209], the c0182730 rhythm-patterns table, and the pattern-menu-draw cluster built on bitmap_set_bit_range_3ae4. (4) The screen-6 tuner-calibration module (c0154338..c0154ea8), confirmed by recon/15's "screen 6's handler c0154e00 ... references '435Hz' and 'BYPASS'": a generic row-draw/row-edit pair (c0154e6a/c0154e8a) dispatched from a settings table at c0184070, backed by leaf row handlers (c0154c64, c0154c78, c0154d40, c0154d54, c0154d84, c0154da0, c0154dd4) and the BYPASS/435Hz label getters. (5) A USB-MIDI string-descriptor subsystem (c0154ec0..c015514c, c0156680..c0156938, c0157480..c01577c8): a 5-slot table at 0xc0119bb0 (168B stride) built/rebuilt/swapped/removed by usb_string_descriptor_build, usb_desc_table_init_or_remove and the hidden usb_desc_table_swap_entries, feeding into the MIDI patch-info/USB-descriptor-sync functions later in the range. (6) A large family of thin per-call-site wrappers (locked_b14_notify_a..j) around a shared locked B14[157]/[544] accessor (c01551c0), and a parallel family of table-callback stubs at c0184070/c0184360-78/c01842cc-310/c0184360s/c0184514-20 for UI "active item reset" and USB-descriptor-sync dispatch. (7) The effect-slot ELF-module load/unload pipeline (c01560c0..c0156304, plus the hidden stage_3b at c0156338), and the USB CPPI/endpoint-DMA init cluster (c01554c0..c015576c). (8) A footswitch/GPIO read cluster (c0156f00, c0157034, c01570a4) for SwitchNrmlSpdRead. Four hidden starts (c0154bc0, c0154bce, c015514c, c0156338) found via tools/fwmap/hidden_starts.py are included as their own rows. Many leaf/guess rows (the table-callback stubs, the per-site notify wrappers, and a handful of single-caller "not traced in detail" helpers) rely on fact-sheet call/ptr@ data rather than full disassembly reads, consistent with the budget used elsewhere in this map.
