# chunk_10: c01453b4..c0149648 (150 functions)

Summary: this range holds three subsystems back to back. (1) c01453b4..c0146e18:
support code for the TI ELF dynamic loader (recon/13, recon/14's "effect
loader"/"effect memory" subsystem) -- a family of refcounted singly-linked-list
insert/release helpers built on the loader-support heap (alloc c0163118, free
c01630b4, both already named elsewhere but their real role per recon/14 is
heap alloc/free, not "locked_subsystem_op"/"validate_and_set_error"), plus the
ELF symbol-record reader/resolver cluster recon/14 already confirmed
(c0146a60, c0146cb4, c0146e18) and a 1676-byte character-class/token routine
(c0146338) not traced in detail. A separate confirmed 16-byte global struct at
0xc01197a0 (word0=value, +4=armed/busy counter, +8=secondary value) is
read/written by c0145da0/c0145dd4/c0145de8/c0146248/c01462d4's table and drawn
to the LCD by the c0145e00/c0145e28/c0145e60/c0145eac UI cluster -- a single
config field with "apply now" vs "stage only" semantics gated by the busy
counter. (2) c0146ee0..c0148408: fixed-point math (c0146ee0, already used
widely elsewhere) and a gain-ramp/effect-apply path (c0148408 and its callees)
feeding 1180-region ramp helpers already named by recon/16. (3) c0148540..
c01494cc: the USB-MIDI output packetizer recon/15 already traced in detail
(state-table dispatch c01489a0 -> c0148740/c0148930/c01488b2, per-cable state
c0116308+12*cable, output ring c0115300/c0116300) plus its footswitch/menu
neighbours c0148a50..c0148fea (roots MainApp/SwitchNrmlSpdRead). (4)
c0149040..c0149640: a cluster of per-command handlers that all lock via
bios_sem_pend/post (B14[154]) and go through effect_slot_lookup (c015c164) /
bridge_status_struct (c0156d68) -- a locked "read/write an effect-slot status
field" family -- ending in a 12-entry jump table (c0184148..c0184174) of
one-call veneers to unrelated big handlers, read by c01462d4 with an index in
range ~11-19 for the earlier 0xc01197a0 struct's "notify" dispatch (same
table-dispatch idiom FWMAP's 00_library_kernel.md flagged).
