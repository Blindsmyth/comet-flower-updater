# DR103 redesign (2026-10-15, offline): fits the slot, ~36k cycles static

Queue item 6. The Hiwatt DR103 (`effects/hiwatt`, `effects/common/hiwatt_*.h`)
did not fit the pedal: **51,464 B against the 40,960 B slot heap**. Its first
pedal build cost **~224k cycles per block** (recon/04), ~25k of which was the
tone-stack solve alone. DO_NOT_FLASH: nothing here has run on the pedal.

## Result

| | before (f8b2855 build) | after |
|---|---:|---:|
| Slot heap (`check_slot_mem.py`) | 51,464 B (over by 10.5 KB) | **34,640 B** (6.3 KB free) |
| `.text` (code region 30,720 B) | 24,512 B | 28,320 B |
| Const blob | 24,700 B (tanh + two knob tables) | 4,096 B (tanh only) |
| Stack frame (stock max 1,536 B) | 1,428 B | 1,404 B |
| State | 324 B | 320 B |
| Static cycles per block | ~50k without the 25k stack solve (estimate) | **~36k** |
| 16x bench, worst max-harmonic / alias | 16.09 dB / -45.6 dB | 16.30 dB / **-46.0 dB** |

DR103D (diagnostic) builds at 35,352 B. Build both with
`ZD2_TEXT_EXTRA=12288 bash tools/build_g1.sh hiwatt "CF DR103" "HIWATT/DR103"`
(and `dr103diag "CF DR103D" "DR103/DIAG"`): stomphacks' 18 KB `.text` budget is
a sanity cap, the binding limits are the 30,720 B code region and the slot heap.

The harmonic error went down almost everywhere (noon 1760 Hz 2.5 -> 0.6 dB).
The worst rows did not change. Four cranked rows lose 3-6 dB of alias floor,
which stays 57-74 dB below the harmonics (the power stage lost its ADAA).

## What changed, and the evidence

1. **Straight-line network derivations** (`tools/gen_hw_nets.py` ->
   `hiwatt_netgen.h`). The topologies are fixed, so the elimination is traced
   once over the sparsity pattern:
   - Tone stack and V1: GTH elimination (positive sums only; plain Gauss lost
     0.21 dB to the 20-ohm wiper floor). The Master pot only loads node D with
     a fixed 242k leg, so it is folded into the output.
   - Back half: Presence only changes two branches, so a Woodbury rank-2
     update of constants computed in double replaces the 101-position table.
   - The stack and the back half share one compact dense tail.
   - Host check `tests/host/build_hiwatt_netgen_test.bat`, against a
     double-precision mna_derive (in band / complex error re peak): stack
     0.0039 dB / -77 dB, V1 0.0003 / -90, back half 0.00005 / -104. Every one
     beats the float mna_derive it replaces.
2. **No knob tables.** The blob holds the tanh table only.
3. **ADAA on V1, V2, V3a and PI only.** The bench masks
   (`tests/host/hiwatt_accuracy.cpp masks`) show the EL34 pair's ADAA adds
   nothing to the worst alias. V1's ADAA is worth ~20 dB of clean-setting
   alias floor.
4. **Stage-major loops with states in locals**, all bit-identical to before
   (36 bench signals, plus a cab-on check):
   - Half-band resampling (6.7k -> ~2k).
   - The preamp fix-up test runs as a branch-free index list (2.6k -> 0.6k per
     stage).
   - DC guard ii 19 -> 9; network loops written as tree sums; cab in two
     passes (ii 79 -> 23).
5. **NFB loop: 482 -> ~258 cycles per sample.** The residual-independent part
   of the back half is computed one iteration ahead, the PI rail ramps per
   block, and the state lives in locals. The bench is unchanged.

## Static cost per block (cl6x -O2, `tools/c6x_cycles.py` + trip counts)

| Part | Cycles |
|---|---:|
| NFB loop (64 x ~258, serial) | ~16.7k |
| Preamp tubes, 3 x (fast pass ii 27 + fix-up list ii 8) | ~7.5k |
| Network derivations (V1 + heads + shared tail) | ~5k |
| Networks per sample (V1 ii 16, stack ii 30) | ~3.1k |
| Resampling, DC guard, cab, output, glue | ~4.2k |
| **Total** | **~36k** (plus cache refill, 19-25 % on other kernels) |

The derivation tail is a measured size/speed trade:
- straight-line: 4.4 KB, ~1.4k cycles;
- rolled rows: ~1 KB, ~4k cycles (in use now).

With straight-line the code region would have only ~0.9 KB of margin.

## 2026-10-18: measured on the pedal, and step 1 of getting it cheaper

USB CPU bench (docs/CF_BENCH_RESULTS_2026-10-18.md): CF Watt alone **39.7k cycles per block** (static estimate
36k), Zoom HW100 21.9k; with it as the 5th CF effect the pedal refused the patch. Target ~22k.

Step 1 (`hiwatt_kernel.h`): the derived networks (HwCoeffs, 372 B, ~5k cycles of derivation per block) are
cached in the slot work buffer (instance[3], as CF Mistrss/CE2) keyed by the six smoothed knob values, and
re-derived only when one changes or on the first block after a load; copied to the stack each block (~100
cycles). Output bit-identical (new 32-bit host test `tests/host/build_hiwatt_kernel_test32.bat`: sweeps, held
knobs, reload with a stale cache). One hw_coeffs call site (it is force-inlined, ~7 KB). Slot memory 35,240 B.
Saves ~5k in steady state; while a knob moves the cost is unchanged (peak). TEST updater
`GUITAR AUDIO 13 - bench + CF Watt cache TEST.exe` (`0cd0ae38`, DR103.ZD2 `871ecc37`): measure CF Watt alone.
Next candidates: the NFB loop (16.7k, serial at 4x), preamp fix-ups, derivation spread over blocks while turning.
