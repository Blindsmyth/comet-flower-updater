# CF Delay (2026-10-18): Comet Flower's DelayMobile on the G1X Four

Owner: "we need a delay of our own". Source: VirtualPedalBoardEngine/Source/MobileDsp/DelayMobileCore.h
(+ MobilePrimitives.h MonoDelayLine, OnePoleTPT, OddShaperTable), the lean line of the desktop DelayProcessor.

- Core `effects/common/delay_g1.h`: step for step the original (300 ms tape glide on Time, no swoop on load;
  main tap + a 20 ms later tap for stereo; feedback through a fixed 3.5 kHz TPT one-pole; tanh with first-order
  ADAA on the write node; 2 s max; power-of-two line never cleared, unwritten cells read as zero). One change:
  the original's ADAA antiderivative is double; here the mean of tanh over a step is computed in float without
  cancellation (atanh(tanh(mid) tanh(h)) / h under 0.25, ln cosh difference above), tanh/ln cosh from the CE-2
  table. Constants as the original computes them (glide 1.0f - expf(...) in float).
- Bench `tests/host/build_delay_accuracy.bat`: the original core compiled from its source as the reference, sample
  for sample, both channels: defaults -131.6 dB, regen 0.92 loud -128.1, regen 0.92 sine -137.5, quiet -108.9,
  sine fb 0.6 -140.1, Time sweep 200->800 ms -128.8, 2000 ms -126.8 (pass < -60). **PASS.**
- Effect `effects/delayx` "CF Delay" (DLYX, 08000f8b, DELAY group): Time 0..2000 (ms), Regen 0..92, Mix 0..100,
  defaults 420/30/30 as the original; mono in, stereo out; 512 KB line + state in the slot work buffer
  (524,308 of 529,200 B); first block after a load resets the counters only. Slot memory 8.5 KB. Kernel host test
  (32-bit, real work buffer) `tests/host/build_delayx_kernel_test.bat`: echoes at 420 ms (L) / 440 ms (R),
  second echo quieter, silence before the first echo with garbage in the buffer, exact bypass, bounded at regen
  92, guard / range / missing-buffer mutes: all pass. Static estimate ~3k cycles per block (branchy: measure).
- Toolchain: stomphacks caps knob max at 1000; local hook `ZD2_PARAM_MAX_MAX` (build_g1.sh: 3018, the stock G1
  delays' Time max), docs/TOOLCHAIN.md "Local change 3".
- Updater `GUITAR AUDIO 16 - bench + CF Delay TEST.exe` (`6b649482`): bench firmware; CF 808/RAT/Muff/Watt (2x)/
  Dyna/Mistrss/CE2/Delay, G1 Gain, CF Tone + the stock counterparts. DLYX.ZD2 `be5e5307`.
- Not tested on the pedal: the knob range 2000 on the pedal UI, the cost, the sound. Bypass cuts the echoes (no
  trails) like the original's pedal-off.
