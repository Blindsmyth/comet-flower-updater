The Exact 9-Byte Surgical Modification

Every byte changed in res1.bin has been verified through independent high-reasoning audits. No heuristic relocations, no code shifts, and zero alteration of peripheral drivers: 

1. 0x61008 (c016d08c): 27 44 05 fc
   -> MVK.L2 2, B0; STW.D2T2 B0, *B15[3] (Early init sets L2CFG mode 2 = 64 KiB Cache / 64 KiB SRAM)

2. 0x61018 (c016d09c): 00 00 d0 e1
   -> .fphead VLIW Fetch Packet Header (Sets bit 24 to declare Slot 3 compact, preventing CPU boot trap)

3. 0x756b0 (c0181728): 02 00 00 00
   -> Late L2CFG Table (Enforces mode 2 across secondary boot routines)

4. 0x77efd (within .cinit RLE stream): 00 82 11
   -> Overwrites '40 1f c0' in the RLE stream to decompress Slot 0 base address to 0x11820000 with 0 stream shift.

🛡️ Critical Breakthrough: Runtime Quiescence Verified

A critical hurdle in embedded DSP modification is runtime race conditions: what happens when a user switches guitar patches while audio interrupts are firing? Our reverse-engineering of the effect loop revealed that Zoom's native engine swaps the effect interrupt pointer with a stock silence stub (0xc016d184) at 118133e0 + 4*slot before reloading. This proves that swapping Slot 0 into L2 SRAM is 100% race-free—the audio hardware is already silenced by design during reload.
