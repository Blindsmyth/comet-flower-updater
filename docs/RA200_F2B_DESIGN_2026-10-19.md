# CF Alembic F-2B + Yamaha RA-200: research and design (2026-10-19)

The missing half of the 1979 *Comfortably Numb* studio rig (Kit Rae): after the pedals the signal split into
Hiwatt DR103 -> WEM 4x12 (CF Watt) and **Alembic F-2B preamp -> two Yamaha RA-200 rotating-speaker cabinets**,
each miked, mixed in stereo. One CF effect: preamp -> RA-200, stereo out. Designed to the C6745 rules
(docs/C6745_DESIGN.md) from the start.

## 1. Alembic F-2B (settled)

Source: R.G. Keen's schematic, geofex.com (posted 07/30/02, "Alembic Tube Preamp F-2B", copyright 1999 R.G.
Keen; link only, the notice forbids local copies). Redraws at moosapotamus.net and in DIY threads are based on
it. Two identical channels; one channel:

| Part | Value |
|---|---|
| V1b (12AX7) | input -> 68k grid stopper, 1M grid leak; plate 100k to B+; cathode 1.5k bypassed 50 uF |
| Tone stack (Fender AB763 values) | 250 pF treble cap, 100k slope, 0.1 uF bass cap, 0.047 uF mid cap; Treble 250k, Bass 250k, Mid 10k |
| Volume | 1M, Bright switch 120 pF across it (treble wiper side to volume wiper) |
| V1a (12AX7) | plate 100k, cathode 1.5k bypassed 50 uF; out 0.1 uF into 1M |
| Supply | ~300 V B+ (voltage doubler, 1.5k/47 uF filter stages) |

It is the blackface Fender front end without a power amp, the same building blocks CF Watt already has: an
input triode stage, a passive TMB stack network, a second triode stage (`hiwatt_netgen.h` stamping, ADAA
triodes). The owner's JUCE notes (`DESIGN_NewAmpModels_2026-08-06.md`) had it blocked for lack of a schematic
with values; this one has them.

Knobs: Volume, Treble, Mid, Bass, Bright. One channel is enough (the two are identical).

## 2. Yamaha RA-200 (partly known)

| Fact | Source |
|---|---|
| 1976, 200 W solid state; 3 x ND90G 90 W amps: one for the rotating speakers, two for the fixed ones | GB Audio data sheet, giampaolonoto.it |
| **3 rotating speakers** (JA1701B) in the top compartment, all at the same speed, **the speakers themselves rotate** (no horn/drum as in a Leslie) | data sheet, Reverb/eBay listings, organforum (via search) |
| 4 fixed JA3502A 12" speakers in the lower cabinet | data sheet |
| Active crossover: with rotation on, the highs go to the rotating speakers; off: everything to the fixed speakers (RA-100 description, "all modules of the RA-200 are in the RA-100 schematic") | organforum via search |
| Controls: volume, bass, treble, reverb, tremolo speed (= **slow speed, adjustable**; **fast is fixed**), footswitch: rotation on/off and slow/fast | several listings |
| Sound: "more open and airy than a Leslie", "organic, mechanical chorus" | owner's notes, Kit Rae |
| Gilmour: Animals (Dogs), The Wall incl. studio *Comfortably Numb*, The Final Cut | giampaolonoto.it, Kit Rae |
| Size 1156 x 735 x 490 mm, 93 kg | data sheet |

**Not found anywhere:** rotor speeds (rpm), spin-up/down times, crossover frequency, rotating-speaker size and
rotation radius, mic placement. The RA-100 is described with speakers on a horizontal spindle; the owner's
notes say vertical for the RA-200: open.

So the model is physical in structure, with the unknowns as calibrated parameters:
- speeds: slow knob range ~0.5..3 Hz, fast fixed ~6-7 Hz (Leslie-like ranges as a start);
- inertia: one time constant per direction (start ~1 s up, ~1.5 s down; a single rotor assembly, unlike the
  Leslie's light horn / heavy drum);
- crossover ~800 Hz, 2nd-4th order (start from the Leslie's 800 Hz);
- radius ~0.2 m (cabinet 735 mm wide), Doppler depth from radius and speed.

Calibration: the studio *Comfortably Numb* solo itself. A sustained note shows the rotation as amplitude and
pitch modulation at the rotor rate; the owner's recording (not in the repo) gives the slow speed and the depth
by spectral analysis (`ua_ab`-style tools). Fast speed and inertia need another reference or the owner's ear.

## 3. Model, shaped for the C6745

Mono in -> F-2B -> crossover -> {lows: fixed 4x12 (biquad cab, both outputs); highs: three rotating speakers}
-> two mics (L/R: Gilmour's two cabinets) -> stereo out.

Rotating speakers: one write per sample into a short line (~2 ms, highs only); per speaker k (phase 2 pi k / 3)
and mic m, a fractional read at delay `d0 + r/c (1 - cos(theta + phi_k + mic_m))` (Doppler) times a directivity
gain `g(theta + ...)` (AM, cone facing the mic), summed per mic. 3 speakers x 2 mics = 6 reads per sample.
- No feedback anywhere: the rule from CF CE-2 applies (writes first, then the reads; the shortest delay d0 is
  chosen above one block, so the reads never touch the block's own writes).
- Rotor angle per sample from a phase accumulator (one short recurrence) and a smoothed speed (inertia); the
  cos/sin per speaker come from the angle by rotation (one complex multiply per sample, not 6 cos calls).
- The F-2B's two triode stages: ADAA triodes as in CF Watt at 1x if aliasing allows (a clean preamp at moderate
  gain), 2x otherwise, decided on the host bench as for Watt.

Cost estimate (static, by analogy with the reworked effects): F-2B ~2-4k cycles per block (two triodes + two
networks), rotary ~2-3k (6 Lagrange reads ~ CE-2's read pass x 6 at 16 samples, filters, phasor), total
~5-7k. In CF Master this path is independent of the Hiwatt path, so it can run inside the Watt NFB loop's idle
units (docs/C6745_DESIGN.md §3c).

## 4. Decisions for the owner
1. Slow-speed control as a knob (as the hardware) plus a fast/slow switch: proposed.
2. Calibrate from your *Comfortably Numb* recording? (a few seconds of a sustained solo note, any format)
3. Studio-only target, or also the live (CE-2) variant: still open (affects CF Master, not this effect).

## 5. Build plan
1. Host reference (double precision, 8x): F-2B from the values above; rotary model with the parameters above.
   Bench: tone-stack response vs the AB763 analytic curve, triode stages vs the CF Watt triodes, rotary:
   Doppler/AM rates and depths.
2. Pedal kernel to the C6745 rules, `*_block_test.cpp` bit-identity against its per-sample form, loop report
   all pipelined, slot memory check.
3. Effect CF RA200 (2 slots if the probe shows that is useful, else 1), measured on the bench (updater 22 line).
