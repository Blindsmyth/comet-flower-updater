# A/B test over USB: CF Watt 4x vs 2x oversampling (2026-10-18)

Owner: test 2x vs 4x oversampling through the USB bridge, like the CPU bench, and see a graphable difference.

## Tools
- `effects/cftone` **CF Tone** (07000f8a): deterministic 12 s program in place of the guitar (0.5 s silence,
  1 s tones 82.4..3520 Hz, 0.5 s silence, 4 s exponential sweep 40 Hz-16 kHz), so both versions get identical input.
- `effects/hiwatt2x` **CF Watt2x** (04000f89): CF Watt built with `HW_OS=2` (hiwatt_amp.h now takes the factor as a
  build option; the 4x build is byte-identical to before; 2x passes the kernel host tests).
- `tools/ua_ab.py`: `capture A|B` (USB ch 3 = guitar FX before master + bench ch 8 cycles), `compare` (finds the
  program, per tone: harmonics, THD, non-harmonic floor = aliasing + noise; sweep spectrograms), `host` (the same
  from the pedal code on the PC: tests/host/ab_render.cpp, build_ab_render.bat, 32-bit).
- Desktop: `CF AB - compare two patches.cmd`; updater `GUITAR AUDIO 14 - bench + AB test (CF Tone, CF Watt2x) TEST.exe`
  (`4bc6de2b`: bench firmware + shootout effects + CF Watt (cached coefficients) + CF Watt2x + CF Tone).

## Result on the PC (pedal code, CF Tone level 25 = 0.125 peak, cab on)
Default knobs (50): no difference (floor within 1 dB, THD identical).
Volume 100 / Master 100 (others 50), dB re fundamental:

| tone Hz | floor 4x | floor 2x | THD 4x | THD 2x |
|---|---|---|---|---|
| 82.4 | -32.9 | -30.2 | -5.1 | -5.0 |
| 110 | -38.0 | -34.6 | -7.5 | -7.4 |
| 220 | -67.7 | -64.1 | -8.8 | -8.6 |
| 440 | -85.6 | -72.3 | -8.0 | -8.0 |
| 880 | -69.6 | -58.4 | -6.6 | -6.6 |
| 1760 | -58.2 | -53.5 | -10.7 | -10.7 |
| 3520 | -52.5 | -39.6 | -48.8 | -53.4 |

Harmonics (the tone) identical; the aliasing floor is up to 13 dB worse at 2x; the sweep spectrogram shows folded
lines at 2x from ~4 kHz fundamentals. Graphs: docs/img/ab_watt_4x_vs_2x_cranked*.png. Keep 4x (as decided
2026-10-15); the pedal run confirms with real hardware and adds the cycles of both.
