## Pedal side (`UA_BENCH` in usb_audio_tap.c)
TSCL (the CPU cycle counter; stock starts it, recon/04) is read at: the Pre looper call (11818bc0), the start
of each slot (`ua_slot_enter`, which replaces the target of the stock veneer 11818eb0: called only by the slot
loop at 11818c04 before each slot's callback; it returns 0x11f03b48 like the stock c01502cc and reads the slot
index at c0184f98; docs/helpers/SLOT_TAP_ARGON_2026-10-17.md + review), the Post looper call (11818c50) and the
TX pack (11818c64). Each block sends 16 words on ch 8: sync 0x7e5a, seq (11 bits) | slots-ran mask << 11, then
slot 1..5 cost, busy (Pre looper -> TX) and the block period as u32 lo/hi. Slot 5's figure also holds the
patch-level stage and the output-EQ slot (subtract the empty-patch baseline). Load % = cost / measured period:
no clock assumption. A Swi that misses a block shows as a period ~2x the median ("slow blocks").
Not covered by "busy": input stages before 11818bc0 and work after the TX pack (stock, constant).

## PC side (`tools/ua_bench.py`)
- `measure`: capture (WASAPI exclusive, bit-exact), decode, per-slot median / p99 / max, busy, period, lost
  frames, slow blocks.
- `run`: fully automatic plan (default: empty baseline; each CF effect and stock counterpart alone; CF Dyna /
  Mistrss / CE2 x5; the two shootout chains). Per test: builds a patch at default knobs (EDTB encoder after
  zoom-zt2 decode_preset; round-trips every slot entry of all 50 factory patches), writes it to patch 50 with
  read-back, sends Program Change, confirms with the current-patch dump (else asks you to select it), waits
  1.5 s, measures. Report: `build/bench/<time>.md/.json`.
- `patch`: write a test patch file offline; `decode`: decode a saved take.
- Tests: tests/test_usb_audio_bench.py (frame encode/decode across the TSCL wrap, skipped chain, packager
  acceptance/refusal, patch encoder). 318 tests pass; all earlier USB builds still reproduce.
