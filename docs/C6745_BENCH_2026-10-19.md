## Steps for the owner
Flash as usual (FIRMWARE UPDATE screen first: hold both footswitches while plugging USB). Power on holding
slot 1 for USB audio.

**1. Bench (desktop `CF Bench - measure patch.cmd`)**, AUTO SAVE off, one effect alone in an empty patch,
default knobs, playing:
1. CF Muff, CF Dyna, CF Mistrss, CF CE2, CF Delay, CF Watt (also Watt cranked).
2. The chain Dyna -> Muff -> Watt -> Mistrss -> Delay (before: refused or near the limit; now should load).
3. An empty patch (baseline).
Listen to each too: they should sound exactly as before.

**2. CF RA200** (MOD group), alone, then after CF Muff: listen in stereo (it is the only CF effect with two
different outputs: L and R are the two cabinets). Rotor 0 / 1 / 2 = off / slow / fast, Speed sets the slow
rate, the rotors spin up and down. Bench it at default knobs, and once while turning Treble (the network
re-derivation runs on those blocks). Its speeds, crossover and rotor size are starting values: say what
sounds wrong (too fast, too deep, too much tremolo) and they get tuned.

**3. CF Master probe**: the steps in `docs/CF_MASTER_PROBE_2026-10-19.md` work on this firmware as well
(ch 3-4 guitar FX, ch 7 DI; only ch 8 is timing instead of the looper).
