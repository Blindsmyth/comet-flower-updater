# Bench of the C6745 reworks + CF Master probe (updater 22, 2026-10-19)

## The updater
`GUITAR AUDIO 22 - bench + C6745 effects + CF Master probe TEST.exe` (desktop,
`build/c6745_bench_2026-10-19/`), sha256 `8dbb8788`.
- Firmware: bench USB firmware `6e20051c` (as updater 17: ch 8 = CPU timing frames for `tools/ua_bench.py`).
- Effects: updater 17's image (`fs_cfloads.bin`) with six files replaced by their C6745 rebuilds and the two
  probes added: image `fs_c6745.bin` `80c6d9fd`, 48 files, directory compact (48 live slots, none deleted).
  The same recipe with the old image rebuilds updater 17 byte for byte (`3fb5c47b`).
- The replaced files differ from the installed ones only in their code (`DATA`): same ids, icons, slot pictures,
  texts, knobs and declared loads. Patches that use them keep working.

## Steps for the owner
Flash as usual (FIRMWARE UPDATE screen first: hold both footswitches while plugging USB). Power on holding
slot 1 for USB audio.

**1. Bench (desktop `CF Bench - measure patch.cmd`)**, AUTO SAVE off, one effect alone in an empty patch,
default knobs, playing:
1. CF Muff, CF Dyna, CF Mistrss, CF CE2, CF Delay, CF Watt (also Watt cranked).
2. The chain Dyna -> Muff -> Watt -> Mistrss -> Delay (before: refused or near the limit; now should load).
3. An empty patch (baseline).
Listen to each too: they should sound exactly as before.

**2. CF Master probe**: the steps in `docs/CF_MASTER_PROBE_2026-10-19.md` work on this firmware as well
(ch 3-4 guitar FX, ch 7 DI; only ch 8 is timing instead of the looper).

To go back: updater 20B (looper on 8) or 17.
