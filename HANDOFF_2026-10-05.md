## 3. Measured results and the next phase

**Measured 2026-10-05** (owner's recordings via VPE, `Documents/VPBE_Takes/`,
pedal on the RIGHT channel of `*_dry.wav`; details in `recon/06`):
- 44.1 kHz confirmed: the 440 Hz tone measures 439.98 Hz (clock tolerance).
- **CPU overrun does not crackle: the pedal UI freezes** (no knobs, no
  patch change, no exit). The audio keeps playing clean, and only a power
  cycle recovers it. The freeze point is Probe Load 60 / 64, i.e.
  **≈96–102k cycles/block** available to one effect.
- **Green 808X + Probe 10 froze at Load 14** (14 × 1600 = 22.4k), so 808X costs
  **≈74k cycles/block on the real pedal**. That matches the static cl6x
  estimate (~74–77k): memory stalls are negligible, and static schedule
  estimates can be trusted for sizing.
- 808X play test passed: it sounds "almost identical" to Green 808 by ear
  (through an interface that compresses the input, so not a precise A/B).
- The declared dspload is bookkeeping only; the pedal does not enforce real
  CPU time.

**Design rule:** keep a single effect at or below **~80k cycles/block** (to
keep the UI responsive). An effect over ~96k freezes the pedal; saved into a
patch, it would freeze it at every load of that patch.

**Next phase: the solo-chain effect** (one effect using the whole DSP:
drive → amp → tone stack → filter cab, sharing one 8x oversampling).
1. ~~Make 808X cheaper~~: **done 2026-10-05, ≈17k cycles/block (static)**.
   The diode equation is normalised to `c·u + sinh(u) = r` (`c` from Drive,
   ~340–500; `r` per sample) and read from a table: cubic Hermite segments,
   8 per octave of |r| from 2^4 to 2^28 (index from the float bits), 9 rows
   in `c` blended with cubic Lagrange weights per block. 27 KB, shipped
   as the manifest `const_blob` (`effects/drv808x/dtab.bin`), regenerate
   with `tools/gen_diode_table.py`. Table error ≤ 4e-6 V; no Newton at all
   (output within −101 dB of table + exact Newton). The C4 history folds
   into one float, and the stage loop is branch-free, so it software-pipelines
   (ii 61). Accuracy vs 32x: worst 1.75 dB (was 1.87; OS-filter droop at
   3.7 kHz), ≤ 0.04 dB below 1 kHz, alias ≤ −58.4 dB (was −55.1: the old
   3-step warm start was not fully converged at high drive).
   Pitfall found on the way: clamping the `c` row position to the inner
   rows snaps `c` at Drive 0/100 (0.5–0.7 dB errors on weak harmonics).
2. **Measure the new 808X on the pedal (next, needs the owner).** `replace`
   the installed Green 808X (same id/version, pedal on another patch), play
   test it, then the cost test: 808X + Probe 10, raise Load until it
   freezes; cost = 96k − Load × 1600. Expect Load ≈ 49 (≈17k). Keep dspload
   80 until measured, then lower it. Remaining per-frame overhead outside
   the stage loop (half-band down-sampling, output) is ~450 cycles/frame
   (~7k/block) if more is ever needed.
3. **Build the solo chain.** **Open question for the owner: which amp.**
   Comet Flower has two real amp models: **Jumpered Tweed** (Tweed Deluxe
   5E3, recommended: lighter, classic with a TS808 in front) and **British
   '71 Head** (Hiwatt DR103, 3 MNA networks at 4x: too heavy as it is).
   Port with a host reference per stage, as for Green 808.

The owner's insight: 808 vs 808X are nearly indistinguishable by ear, so the
cycles 808X spends buy little audible benefit. Spend the solo chain's budget
where it is audible (preamp and cab).

## 4. How to do things

```bash
# build an effect (stomphacks build + G1 conversion) -> build/<FILE>.ZD2
bash tools/build_g1.sh <effects-folder> <ICON LABEL> <SLOT/PICTURE>
# install a NEW effect (write test first)
/c/Users/z/zoomlab/stomphacks/.venv/Scripts/python.exe tools/pedal_g1.py writetest build/X.ZD2
/c/Users/z/zoomlab/stomphacks/.venv/Scripts/python.exe tools/pedal_g1.py install   build/X.ZD2
# update an installed effect (same id + version); pedal must be on another patch
.../python.exe tools/pedal_g1.py replace build/X.ZD2
# patches
.../python.exe tools/backup_patches_g1.py <dir>      # read-only
.../python.exe tools/patch_g1.py write <loc> <file.ZPTC> [<to-loc>]
# backups (read-only)
.../python.exe tools/backup_g1.py <dir>
# inspect / audit
.venv/Scripts/zd2 inspect file.ZD2 ;  .venv/Scripts/zd2 audit dir/
# host verification (MSVC)
tests/host/build_drv808_compare.bat           # Green 808 vs Comet Flower original
tests/host/build_accuracy.bat                 # builds + runs the bench -> build/host/acc
python tests/host/ts808_accuracy.py acc       # score vs 32x reference (arg = folder under build/host)
# variants: tests/host/build_accuracy.bat <folder> /DNAME#value  (# = '=' for cmd)
# cycle estimate of a kernel without the pedal: compile with
#   cl6x --c99 --opt_level=2 --silicon_version=6740 --abi=eabi --mem_model:const=data
#        --mem_model:data=far_aggregates -k --asm_directory=<dir> -c drv808x.c
# (copy drv808x.c, effects/common/*.h and the stomphacks build's sh_params.h
#  together), then: python tools/c6x_cycles.py <dir>/drv808x.asm
# (cycles per block / per branch; multiply by trip counts; for an SPLOOP use
#  (trips + stages - 1) * ii). It reproduced the old 808X's measured 74k.
```

## 5. Safety rules (keep)

- **AUTO SAVE off** on the pedal during experiments.
- Never save a patch with an **untested** effect; it is a known brick path.
  Recovery net: the G1 firmware-update mode (hold both footswitches while
  connecting USB) plus Zoom's v2.00 updater (untested).
- Ask the owner before every new class of write. The established workflow
  (writetest → install → replace) has been approved repeatedly.
- Never leave a transfer half-done: keep the pedal powered if a tool reports
  UNRESOLVED.
- Stock state size precedent: plain G1 effects use ≤ 392 B of contiguous
  state undeclared, which is why `build_g1.sh` caps at 392.

## 7. Key facts (quick reference)

- DSP: TMS320C6745**DPTP3**. Silicon revision 3.0, commercial grade, speed
  grade "3": 375 MHz per the datasheet nomenclature; TI's product page says
  456. The real clock is set by Zoom's firmware PLL and is not measured.
  (It no longer matters: the effect budget is measured directly.)
  Flash: MX25L3233F, 4 MB. Likely (MS-50G sibling): 8 MB SDRAM
  EM638165TS-7G, WM8782 ADC, PCM5101A DAC (`recon/07`).
- Audio callback: 16 frames × 2 channels, float32, in place at `ctx[1]`.
  **44.1 kHz confirmed.**
- **Effect budget: UI freezes at ~96–102k cycles/block; design to ≤ 80k.**
  Green 808X = ~74k (measured, Newton build); table build ≈17k (static,
  not yet measured). Probe Load step = 1600 cycles.
- G1 container:
  - target bit `0x02` (present in every stock effect);
  - header bytes 0x10 = 01, 0x18 = 80, 0x58 = slot count;
  - ICON block: 1-bpp BMP, 23/24×30;
  - the trailer is packer filler, and the pedal does not check the CRC.
- The **slot picture** is ELF image-list entry 0, in LCD page format (8 rows
  per byte, LSB at the top). A blank picture shows as "BYPASS"/empty.
- Patch slots:
  - id `0x0` = empty;
  - id `0x1` = the second half of a double-width effect.
- Zoom TS Drive (for comparison):
  - 4x IIR oversampling;
  - an asymmetric piecewise-quadratic clipper (+0.925 / −0.487);
  - pre-clip gain of only 3.5–26x;
  - aliasing −35 dB, against our −55 dB.
