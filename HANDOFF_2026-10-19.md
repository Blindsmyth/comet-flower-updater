## 2. Technical Architecture & Memory Budgets

### A. CF Master (1979 Comfortably Numb Rig)
- **Signal Chain**:
  ```
  Input -> Ram's Head Muff (2x) -> Electric Mistress (1x) -> MXR Delay 480ms (1x)
        -> Split:
           [L/R Center] Hiwatt DR103 (2x) + WEM Cab (9 biquads)
           [Stereo L/R] Alembic F-2B Preamp (1x) -> Yamaha RA-200 3-Rotor Pair (6 Lagrange reads + 6 biquads)
  ```
- **State Guard Offset**: In stomphacks, `SH_STATE_GUARD_WORD` is at byte 64 (`instance[2]` offset 16). `CfmKernelState` is strictly kept at 52 B (words 0..12) so it never collides with the guard word.
- **Work Buffer Budget**: Single slot work buffer (`0x81330`) is 529,200 B.
  - `MuffState` (132 B) + `HwState` (292 B) + `HwCoeffCache` (396 B) + `RaState` (848 B) + `RaCoeffs` (160 B) + `MistressState` (2,120 B) + `DelayState` (524,308 B) = **528,180 B total**, leaving 1,020 B safety margin.
- **Co-Scheduling**: Independent RA-200 biquads, angle phasor, and 6 Lagrange reads co-scheduled within the ~200 idle cycles of the serial Hiwatt NFB loop in `cfm_watt_ra_block`.
- **Compile-Time Switches**: `CFM_STAGE_OFF_MUFF`, `CFM_STAGE_OFF_MISTRESS`, `CFM_STAGE_OFF_DELAY`, `CFM_STAGE_OFF_WATT`, `CFM_STAGE_OFF_RA200` allow compiling isolated sub-chains for benchmarking.
